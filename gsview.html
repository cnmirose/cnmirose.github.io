Ghostview for WINDOWS, OS2 PCs and MACs

You will need a postscript viewer like "ghostscript" to view postscript files. I searched using the "archie" search engine available at the RU web site (keyword "gsview") and found many sites where the software resides. I've sucessfully down-loaded the requisite software for my Windows-95 PC at home from the ftp.cs.umn.edu archive. What would be even nicer is a latex -> html translator or some other such (with typesetting for equations)... oh well.

An ftp/web site for MACs has been provided by your classmate Allen Onweller:

http://www.glyphic.com/glyphic/projects/macgs.html (description and links)
the actual program and assosicated file(s) may be downloaded via ftp at:
ftp://ftp.cs.wisc.edu/pub/ghost/aladdin/mac/ (programs and readme file)
or
ftp://ftp.cs.umn.edu/pub/typesetting/postscript/aladdin/mac/ (programs and readme file)
Happy hunting!

For IBM-compatible PCs I've provided hypertext links to these below:

  • unzip.exe (compression/decompression program)
  • gsview14.zip (a bunch of stuff... decompress and read README.GV)
  • gs353ini.zip (library files)
  • gs353dos.zip (did not load this one for windows)
  • gs353os2.zip (did not load this one for windows)
  • gs353w32.zip MS-Windows Win32 Aladdin Ghostscript
  • gs353win.zip MS-Windows 3.1 Aladdin Ghostscript
  • gs353fn1.zip Aladdin Ghostscript font files (did not load these)

Here are the two ftp sites and directories for unzip and gsview:

  • ftp.cs.umn.edu -> /pub/typesetting/postscript/aladdin/ (gsviewstuff)
  • ftp.cs.umn.edu -> /dept/users/dkim/pc/archive-utility/unzip.exe (decmompression program)

There's quite a bit of stuff to download. I needed about 3-4 Meg total (not including the 1 Meg font file) , so make sure you have a block of time to do it and about 7-8Meg for the decompressed files. Good luck.
