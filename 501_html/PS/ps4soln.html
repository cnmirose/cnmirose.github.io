Problem 6 This is one of the annoying things about statespace form. You can't do things that you think you should be able to do. There are at least two different ways to think about it. The most rigorous is to use linear algebra and consider the resolvent matrix (sI-A)-1. First note that the transfer function of a differentiator is H(s)=s; i.e., the numerator (s) contains a higher order term than the denominator (1). The determinant of (sI-A) must be of order n where n is the order of matrix A. The inverse can be found by composing the ``adjugate matrix'' for (sI-A). If you don't know what this means, don't worry and skip to the next argument which does not involve linear algebra. Since each term in the adjugate matrix is formed by finding the determinant of the smaller matrix formed by deleting corresponding the row and column of (sI-A), the order of each cofactor can be at most n-1 in s. Finally the inverse is found by dividing the adjugate matrix by the deteminant (which must be of order n in s). So, in total (sI-A)-1 cannot have any term whose numerator is of higher order than it's denominator. Which means that H(s) = CR(s)B + D cannot have numerator terms of higher order than the denominator. So differentiation is not possible.

Now all this being said, there are very sneaky ways one might try to make an integrator if you had an infinite state system (very nasty idea). But the basic method is based on Fourier transforms. What you do is use the fact that the integral of a sinusoid differs only in sign and scale from its derivative. Thus, you could in principle apply an infinitely sharp filter at each frequency (infinite state filter), integrate, scale properly and add up all the results from all the (infinite number of) frequencies. Needless to say, this is impractical :)
