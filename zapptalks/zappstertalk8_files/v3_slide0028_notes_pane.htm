And by the way, that powerpoint file is about the same number of bits as a cellular call lasting 5 minutes, so you can see that even in a 3G system, the music CD or DVD uses the system capacity that could have delivered thousands of phone calls, and why is has to cost so much.  If the 3G phone call cost just 1 cent a minute-- much less than it does today-- the powerpoint file would cost a reasonable 5 cents, but the CD would cost $50 and the DVD would cost $500.
You can see why cellular deliver of these files isn’t in the cards, but how about home delivery?
