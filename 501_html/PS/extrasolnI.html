2.
(a)

The matrix difference equation for the demon problem is given by

xn+1=Axn

where


The complete metric space on which the mapping is defined consists of the real non-negative vectors (although it could also be defined on all the real vectors, or even on all the complex vectors for that matter).

First notice that the zero vector is a fixed point of the mapping (even though for this problem we start out with a non-zero vector). We also notice that any vector [a,a, ... a] is also a fixed point. As almost a side issue, for the initial conditions specified in this problem we assume the components must sum to 1 so a=1/N.

So, the mapping cannot be a contraction! Why? Because a contraction mapping can have only one unique fixed point in the complete metrix space over which it is defined. This latter point is why we have to include the zero vector in the space. The space of non-negative vectors without the zero vector is not a complete metric space; i.e., consider the cauchy sequence [1/n,1/n,...1/n] which has limit point not in the space.

By the way, if you tried to show that all three of our matrix norms were that was not enough. Why? Because you did not consider all possible norms. All you need is to find one valid norm (which forms a complete metric space) which is <1 for the mapping to be a contraction, and it's impossible to consider ALL possible norms. As a concrete example, let's say we only knew about the norm and were given matrix


The column norm is and we're naively thinking ``not a contraction.'' However, up comes Josephine Smartalek with a definition of some exotic beast called the ``row norm'' with ||A||1= 0.8 which proves that the mapping using A is a contraction. The fixed point is the zero vector by the way.

This is an important point. We pick our norms for convenience in the problem at hand. Any one will do as long as it is a valid norm (distance measure) and it forms a complete metric space with the region in which we're interested.
